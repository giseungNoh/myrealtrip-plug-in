# 목적

이 플러그인에서 **유일하게 마이리얼트립(MyRealTrip)과 실제로 통신하는 스킬**이다.
`myrealtrip` MCP 서버(`https://mcp-servers.myrealtrip.com/mcp`, `.mcp.json`에 등록됨)를 통해
목적지·날짜에 맞는 실제 상품(투어, 입장권, 액티비티, 숙소 등)을 검색하고, 있으면 추천 링크를 붙인다.

## 절차

1. 이 스킬을 처음 쓰는 세션이면, 먼저 `myrealtrip` MCP가 실제로 어떤 도구(tool)를 제공하는지
   확인한다 (Codex가 MCP에 연결되면 도구 목록을 조회할 수 있다). 도구 이름과 파라미터는
   버전에 따라 달라질 수 있으므로 매번 코드에 하드코딩하지 않고, 연결 시점에 확인한다.
2. 일정표에서 "티켓/예약이 필요해 보이는 항목"을 골라낸다. 판단 기준:
   - 유명 관광지·박물관·전시처럼 통상 입장권이 필요한 곳
   - 사용자가 "투어로 가고 싶다"고 말한 곳
   - 도보 산책, 개인 식당처럼 예약이 필요 없어 보이는 곳은 건너뛴다.
3. 골라낸 각 항목에 대해 목적지/장소명/날짜를 파라미터로 MCP 검색 도구를 호출한다.
4. 검색 결과가 있으면 상품명, 가격(있다면), 예약 링크를 일정표 옆이나 캘린더 이벤트 설명에 추천 형태로 붙인다.
   검색 결과가 없으면 억지로 비슷한 걸 지어내지 않고 "이 항목은 마이리얼트립에서 상품을 찾지 못했어요"라고 말한다.
5. 여러 후보가 나오면 1~2개만 추려서 제시한다 (선택 피로를 주지 않기 위해). 나머지는 "더 보기"로 남긴다.

## 정직성 원칙 (중요)

- MCP가 실제로 반환한 상품·가격·링크만 사용한다. 마이리얼트립 상품명이나 가격을 추측해서 만들지 않는다.
- MCP 호출이 실패하거나 도구를 찾을 수 없으면, 사용자에게 실패했다고 솔직히 말하고 대신 일반 웹 검색으로
  참고 정보를 찾아볼지 물어본다 (그 경우 "마이리얼트립 상품"이 아니라 "참고용 정보"라고 구분해서 표시한다).
- 이 스킬은 예약이나 결제를 대신 진행하지 않는다. 링크를 보여주고 사용자가 직접 누르게 한다.
