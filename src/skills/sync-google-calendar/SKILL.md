# 목적

`build-itinerary`가 완성한 일정표(`./travel-cart/<trip-id>-itinerary.md` + `<trip-id>.json`)를
읽어서 구글 캘린더 이벤트로 등록한다.

# 중요한 전제

이 스킬은 **구글 캘린더 자체에 접속하는 코드를 직접 만들지 않는다.**
Codex 환경에 연결된 구글 캘린더 커넥터(MCP)를 사용한다.
OAuth 인증·토큰 저장·갱신은 커넥터에 위임하고, 이 스킬 안에서 직접 다루지 않는다.

사용자 동의 없이 이벤트를 만들지 않는다 — 등록 전 반드시 미리보기를 보여주고 확인을 받는다.

# 데이터 소스

우선순위대로 읽는다:
1. `./travel-cart/<trip-id>-itinerary.md` — `build-itinerary`가 저장한 내부 일정표
2. `./travel-cart/<trip-id>.json` — `day` 필드가 채워진 장소 목록 (주소·좌표·리뷰 비율 등 포함)

# 이벤트 유형 3가지

장소 성격에 따라 이벤트 형태를 다르게 만든다.

## 유형 A — 숙소 (체크인~체크아웃 기간 이벤트)

- **제목**: `🏨 숙소명 (체크인~체크아웃)`  
  예: `🏨 스스키노 부티크 호텔 (9/1 체크인 ~ 9/4 체크아웃)`
- **일시**: 체크인 당일 오후 3시 ~ 체크아웃 당일 오전 11시 (기본값, 숙소 정책 모르면 이 값 사용)
- **장소**: 숙소 주소 (Google Maps 링크)
- **설명**:
  ```
  마이리얼트립 예약 링크: [링크]
  Google Maps: [지도 링크]
  ```

## 유형 B — 장소 (시간대별 이벤트)

장바구니에서 발굴한 로컬 스팟 — 식당·銭湯·카페·동네 산책 등

- **제목**: `장소명 (종류)`  
  예: `さかえ湯 (銭湯)`, `奥の湯 (銭湯)`, `つきさむ温泉 (온천)`
- **일시**: 시간대 기준 블록
  - 오전 → 10:00~11:30
  - 점심 → 12:00~13:30
  - 오후 → 14:00~16:00
  - 저녁 → 18:00~20:00
  - 여백 슬롯 → 해당 시간대, 30분 블록
- **장소**: 현지어 주소 (Google Maps 링크)
- **설명**:
  ```
  🗾 현지어 리뷰 비율: 약 82%
  📍 주소: 中央区北10条西3丁目
  🔗 발굴 출처: https://ameblo.jp/...
  🗺️ Google Maps: https://maps.google.com/...
  ```
- 여백 슬롯은 제목을 `🚶 자유 탐방 (여백)`으로 표기하고 설명에 "이 시간은 비워두세요 — 근처를 걷다 우연히 발견한 곳에 들러보세요"라고 넣는다.

## 유형 C — 액티비티 (별도 이벤트)

마이리얼트립에서 예약한 투어·체험

- **제목**: `🎯 액티비티명`  
  예: `🎯 삿포로 銭湯 입욕 예절 체험`
- **일시**: 액티비티 실제 시작~종료 시간 (모르면 오전 10시 기준 2시간 블록)
- **장소**: 집합 장소 주소
- **설명**:
  ```
  마이리얼트립 예약 링크: [링크]
  가이드 연락처: (예약 확인서에서 확인)
  ```

# 절차

1. **커넥터 확인** — 구글 캘린더 커넥터가 연결돼 있는지 확인한다. 없으면 연결 안내 후 멈춘다.
2. **소스 읽기** — `<trip-id>-itinerary.md`와 `<trip-id>.json`을 읽어 이벤트 목록을 구성한다.
3. **여행 날짜 확인** — 실제 출발일을 사용자에게 확인한다. Day 1 = 출발일로 날짜를 계산한다.
4. **미리보기 제시** — 등록될 이벤트 전체를 아래 형식으로 먼저 보여준다:

   ```
   📅 등록 예정 이벤트 (총 N개)

   [숙소]
   🏨 스스키노 부티크 호텔 — 9/1(월) 15:00 ~ 9/4(목) 11:00

   [Day 1 — 9/1(월)]
   さかえ湯 (銭湯) — 14:00~16:00 / 中央区北10条
   🚶 자유 탐방 — 16:00~16:30

   [Day 2 — 9/2(화)]
   奥の湯 (銭湯) — 10:00~11:30 / 北区北31条
   🎯 銭湯 입욕 예절 체험 — 14:00~16:00
   ...

   이대로 등록할까요?
   ```

5. **사용자 확인 후 등록** — "예"가 나오면 유형 A → B → C 순서로 이벤트를 만든다.
6. **완료 요약** — 등록된 이벤트 수와 캘린더 링크를 보여준다.

# 하지 않는 것

- 사용자 동의 없이 캘린더에 이벤트를 만들지 않는다.
- 구글 인증 토큰·API 키를 이 스킬 안에 저장하거나 직접 다루지 않는다.
- 유명 관광지 입장권 일정을 억지로 채워 넣지 않는다 — 이 플러그인의 장바구니에는 그런 항목이 거의 없다.
- 시간대를 모르는 항목에 임의 시간을 넣지 않는다 — 기본값(위 유형별 기본 시간)을 쓰고 그 사실을 사용자에게 알린다.
